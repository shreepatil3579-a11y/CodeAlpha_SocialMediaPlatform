\# CodeAlpha Social Media Platform



A mini full-stack social media platform developed as part of the CodeAlpha Full Stack Development Internship - Task 2.



\## 📌 Project Overview



CodeAlpha Social is a mini social media web application where users can register, login, create posts, like posts, comment on posts, view user profiles, and follow or unfollow other users.



The project demonstrates frontend development, backend API development, authentication, database integration, and CRUD operations.



\## 🚀 Features



\- User Registration

\- User Login \& Logout

\- Password Hashing

\- JWT Authentication

\- Create Posts

\- View Social Feed

\- Like / Unlike Posts

\- Add Comments

\- Delete Own Comments

\- Delete Own Posts

\- User Profiles

\- Follow / Unfollow Users

\- Followers \& Following Count

\- MongoDB Database Integration

\- Responsive User Interface
